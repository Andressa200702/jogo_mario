# 🍄 Super Mario Jump Game

Um jogo de plataforma simples inspirado no Super Mario, feito com HTML, CSS e JavaScript puro.

## 🎮 Como jogar

- Pressione **qualquer tecla** para pular
- Desvie dos canos que vêm na sua direção
- Quanto mais tempo sobreviver, maior o seu score!

## 🕹️ Funcionalidades

- Tela de início com logo do Super Mario
- Personagem com animação de corrida e pulo
- Canos gerados automaticamente como obstáculos
- Sistema de pontuação em tempo real
- Tela de Game Over com opção de reiniciar

## 🛠️ Tecnologias

- HTML5
- CSS3 (animações)
- JavaScript (vanilla)
